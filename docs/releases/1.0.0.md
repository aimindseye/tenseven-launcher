# TenSeven Launcher 1.0.0

First 1.0 release of the standalone launcher for Android 14 and newer.

- BlackBerry 7 and BlackBerry 10 home layouts, keyboard search, shortcuts, themes and wallpapers.
- Hub conversations, inline reply, read/unread, snooze, reminders, calls, contacts and calendar.
- All ten Hub navigation actions stay in one horizontal row; smaller windows scroll sideways.
- Home notification icons offer compact or show-all display, with app-specific Hub navigation.
- BB10 Active Frames retain the last eight opened apps. Available media, calendar and optional notification summaries enhance those cards.
- Optional Notes, Tasks/Remind, Calc Plus, Sound Profiles and games.
- Widgets page with provider configuration, reordering, height controls and lifecycle recovery.
- Device profiles, responsive layouts, keyboard diagnostics and optional storage dial.

## Installation and identity

Install `TenSeven-Launcher-1.0.0.apk`. Package: `io.github.aimindseye.tenseven`;
version name: `1.0.0`; version code: `18`; minimum Android: 14 (API 34).
Use the existing registered signing key for updates. A debug installation is a separate app.
The release APK is signed during the owner's local build; CI APKs are unsigned candidates.

## Permissions and limits

Notification access is optional for basic launching and recent-app cards. It enables Hub
notifications and media/notification summaries. Calendar requires its own permission and
calendar selection in Hub settings. Apps choose which media information they expose.

Word, Excel and PowerPoint have ordinary recent-app cards; automatic document previews
and manual file linking are not available. Screen sharing requires Android's capture
consent and is a separate preview, not automatic Recents snapshots. Protected content
may not be captured. Closing a frame removes the launcher card; it does not force-stop an app.

P2/P3 engineering is merged. Titan 2 has owner testing; Titan 2 Slim, Zinwa Q25,
Zinwa P26 and ordinary touchscreen hardware still require recorded physical qualification.
Emulator tests do not certify every device. See the user guide and device qualification matrix.
