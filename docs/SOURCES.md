## Changes made to the imported Sable Start sources

Everything else under `app/src/main/java/io/github/aimindseye/tenseven` is as it is in SableOS at the pin above.

| File | Change |
|---|---|
| `model/AppGlyphs.kt` | `AppGlyph.phosphor` is now `AppGlyph.tabler`; every glyph name points at a Tabler outline icon |
| `model/TablerGlyphPaths.kt` | New, generated by `tools/tabler_icons.py` |
| `ui/SableGlyphIcon.kt` | Draws the Tabler outline paths as 2-unit round strokes in a 24-unit box (was Phosphor fills in 256) |
| `platform/PermissionChangeSignal.kt` | New. `PackageManager.OnPermissionsChangedListener` is a system API; reached by reflection so the code builds against the public SDK |
| `platform/UserContexts.kt` | New. `Context.createContextAsUser` is a system API; reached by reflection, null where Android refuses |
| `platform/LauncherAppsRepository.kt` | Uses `UserContexts` instead of `createContextAsUser` |
| `SableStartActivity.kt` | Uses `PermissionChangeSignal` instead of the system listener |
| `AndroidManifest.xml` (new, in `app/src/main`) | Derived from SableStart's; drops the signature permissions and adds Tenseven's name and icon |
| `app/src/test/.../StartTextTest.kt` | Reads strings from `src/main/res` of this repository |
| `res/values/tenseven.xml`, `res/drawable/ic_tenseven_*`, `res/mipmap-anydpi-v26/ic_tenseven*` | New: Tenseven's name and launcher icon, and Tenseven's own strings (Launcher Settings, BlackBerry 7 menu) |
| `ui/SableStartScreen.kt` | Default-app starting icons, bell and speaker row, type-to-search switch, Launcher Settings entry, return-to-Home callback; weather code removed |
| `SableStartActivity.kt` | Also: BlackBerry 7 layout hosting and the BlackBerry 10 detour, icon size, widget list, `onPause` detour end |
| `model/HomeLayout.kt` | Glance widgets: weather removed, alarm added |

### Extra apps ported from SableOS (`app/.../extras/`)

Calc Plus, Notes and the ten games come from the SableOS patch set at the pin above. Sound Profiles comes from SableOS patches
0076, 0077 and 0085 (profile model, applier, screen), rewritten to use Tenseven's package names and a private palette. Provenance
and licences for these and the Mink ports are also listed in `THIRD_PARTY_NOTICES.md`.

## Package rename

The sources were renamed from `org.sableos.start`, `com.sable.start` and `org.sableos.design` to
`io.github.aimindseye.tenseven` and `io.github.aimindseye.tenseven.design` (directories moved with
`git mv`, so history follows). Strings that name SableOS components are unchanged on purpose: the intent
actions (`org.sableos.start.action.*`), content provider authorities (`org.sableos.*.snapshot`,
`org.sableos.appearance`) and package names of the SableOS apps (`org.sableos.messages`, ...), because they
identify those apps and providers when Tenseven runs on SableOS.
