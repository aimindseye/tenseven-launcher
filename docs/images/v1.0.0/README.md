# TenSeven Launcher 1.0.0 screenshots

Owner-supplied Titan 2 captures from November 3, 2026, uploaded as
`tenseven-1.0.0-docs-ready.zip`. These are the supplied 640-pixel-wide PNGs, copied without
pixel changes. The set documents visible release UI; it is not multi-device qualification.
The README and user guide link to this versioned folder so older captures remain distinguishable.

## Review notes

- Hub shows ten actions on a single row. Peek has rounded corners.
- Widget Edit mode shows Shorter/Taller and Up/Down/Remove controls.
- Both automatic settings sequences have BlackBerry 7 selected. Their filenames are script labels,
  not proof of the active home style. Only selected settings images are included and captions
  describe the visible controls. `launcher-settings-bb7-10.png` is used for its shared lock controls.
- `notification-display-settings.png` shows the dials, including storage enabled. The show-all
  notification switch is visible in `launcher-settings-02.png`, with the switch off.
- `home-empty.png` shows no frames and a usage-access guidance banner; it is not a permission-granted example.
- `frame-integrations.png` does not show the lower TenSeven-app controls.
- The Contacts view labelled `hub-navigation-end.png` is omitted. Existing app-grid, test-conversation
  and sample note/task captures are used where they illustrate the documented feature.

## Remaining capture gaps

The upload does not contain current first-run setup/permission screens, a clearly identified
BB10 Launcher Settings sequence, or a show-all-notification-icons-enabled example. Those flows
remain documented in text. No old screenshot is presented as evidence for these flows.

To capture replacements, see [the screenshot guide](../../SCREENSHOTS.md). Review the active
home style and visible settings before naming the files, and use sample notification content.
